# a-shorokhov: лица и модельный слой

Изолированная поставка по `docs/tasks-shorokhov.md`. Автор Git: a-shorokhov.
В ней сохранена выполненная работа; основные `apps/`, `services/`, `prompts/`,
Compose и документы команды этим коммитом не заменяются. Поставка ещё не
подключена к общему приложению.

## Состав

- `services/face/`: YOLOv8-face, buffalo_l 1:1, liveness только при проходе;
  HTTP-контракт, запуск, Dockerfile, автономные и реальные проверки.
- `apps/api/src/model/`: getModel, GigaChat/Ollama, проверяемая формулировка,
  smoke-проверка на явно обозначенных тестовых фактах.
- `apps/api/test/model.test.ts`: формат ответа, факты, OAuth, ошибки и таймауты.
- `prompts/`: инструкции модели, формат ответа, запуск и материалы для алисона.
- `reports/`: результаты полного прогона пакета и HTTP-проверки.

Веса, Ollama, фотографии, .env, ключи, Python-окружение, node_modules и кэши
не включены. Команды скачивания и список настроек есть в README компонентов.
Оригинальный пакет фотографий лежит в корне основного репозитория.

## Быстрая проверка

Из этой папки, Node >=22:

```sh
cd apps/api
npm ci
npm run build
npm test
```

Face — Python 3.12, из этой папки:

```sh
cd services/face
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest -v test_face.py
.venv/bin/python download_models.py
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

Во втором терминале из `services/face`, подставить точное имя каталога пакета
(на macOS возможно составное Unicode-написание):

```sh
.venv/bin/python smoke.py '../../../../Первый пакет'
.venv/bin/python check_package.py '../../../../Первый пакет'
```

Для модельного smoke сначала запустить Ollama и скачать `qwen3:4b`, затем из
`apps/api`: `MODEL_PROVIDER=ollama npm run smoke`. Промпт подхватывается из
`prompts/` этой поставки. Для GigaChat нужен локальный ключ, см. `prompts/README.md`.
