# Три фронта, один стек

Натив не нужен. Браузер с камерой (проходная, заведение) и геолокацией (телефон). Стек: Next.js (или тот же React) + Tailwind + shadcn. Второй UI-kit не подключать. Админ и руководитель — один UI, две задачи.

## Когда вызывать

- Каркас маршрутов, вёрстка ролей, камера, мобильный телефон.
- Пустые/загрузка/ошибки, русский копирайт.

## Маршруты (имена можно сменить, роли нельзя)

| Роль | URL | Устройство | Обязательные экраны |
| --- | --- | --- | --- |
| Контролёр | `/gate` | планшет/ПК | выбор человека, вход/выход, превью камеры, результат allow/deny + причина |
| Рабочий | `/phone` | телефон | выдача подтверждения один раз; кнопка «подтвердить»; статус смены; индикатор отправки гео |
| Админ + руководитель | `/admin` | компьютер | люди + заведение эталона; журнал попыток; кто внутри; зоны; аналитика; помощник |

Общий логин — простой pin/роль на хакатон ок, не SSO. Не строить четвёртое маркетинговое приложение.

`/pitch` — опционально, скилл `/hackathon-pitch`.

## Состояния

Каждый экран: **empty / loading / error / success**.

- Gate empty: «Выберите сотрудника и направление».
- Gate error: текстом `reason_human` с сервера, не `Error: 403`.
- Phone empty: «Подтверждение ещё не выдано» + как получить.
- Admin empty: «Никого не заведено — добавьте человека с эталоном».
- Аналитика без точек: «Нет данных», не холодная теплокарта.

## Камера и гео

- Планшет и админ: `getUserMedia`, превью, кнопка кадра. Нет камеры — понятная ошибка и файл-загрузка как запас (судья может принести фото).
- Телефон: гео с согласия; если отказали — инструкция и демо-кнопка имитации (`/shift-zones`).
- Не требовать HTTPS-сертификат от Сбера; localhost / ngrok описать в `docs/run.md`.

## Mobile

`/phone` — одна колонка, крупные кнопки, не hover. Gate на планшете — крупный статус (зелёный/красный) читаемый с метра.

## Модульность

- `app/gate`, `app/phone`, `app/admin` — разные деревья.
- Общий `lib/api.ts`. UI не считает `allowed` и не хранит эталон лица.
- Не править сервер решения прохода «заодно с кнопкой».

## Анти-паттерны

- Один экран на все роли с гигантским `if`.
- Английский UI.
- Проход «офлайн» с галочкой контролёра.
- Lorem, второй UI-kit, лендинг «Welcome».

## Первое действие

Три маршрута-заглушки с русскими заголовками ролей и ссылками между ними. Затем живая камера на `/gate` и `/admin` enroll.
