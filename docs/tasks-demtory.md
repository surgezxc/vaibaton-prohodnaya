# Demtory — проходная и телефон

Источник правды: [architecture.md](architecture.md), [roles.md](roles.md), [decisions.md](decisions.md), [hackathon-plan.md](hackathon-plan.md). Скиллы в `.cursor/` могут врать (там ещё passkey и «телефон показывает QR»). Делай как в схеме, не как в скилле.

## Что изменилось

- `POST /attempts/:id/scan` шлёт подпись nonce попытки. На привязке телефон регистрирует открытый ключ (`POST /devices`, поле `public_key`, ECDSA P-256). Скопированный JWT без ключа — отказ «чужое устройство».
- QR: `/gate` открывает, `/phone` сканирует.
- Обрыв wifi попытку не отменяет. `POST /cancel` только когда экран закрыт и клиент ещё достучался до API. Мёртвую связь гасит `ttl` на сервере.
- Гео раз в 60 с только пока `/phone` на экране и телефон разблокирован. В фоне не обещаем.

Не пиши сервер. Не придумывай новые маршруты.

## 1. Цель и Д11

Собрать два живых экрана: планшет контролёра `/gate` и телефон рабочего `/phone`, чтобы контролёр открыл одноразовый QR, телефон его отсканировал, планшет отправил кадр КПП, сервер ответил пропуском или русской причиной — и чтобы в открытой смене телефон слал гео и жал кнопки зон.

На защите (Д11) объясняешь только это: как открывается и отменяется QR, как телефон сканирует, как уходит кадр на `decide`, как идут гео и кнопки. Чужой каталог не защищаешь.

## 3. Экраны, вызовы, поля

Роли Keycloak: на `/gate` учётка `gate`, на `/phone` — `worker`. API смотрит `sub` из JWT, не id из тела. Клиент не считает «пропустить».

### `/gate` — контролёр, планшет

Обязательный сценарий из схемы: вход/выход, снять лицо, показать QR с планшета, показать пропуск или причину отказа.

Как в §«Проход» и решении 2: контролёр **начинает** проход — выбирает вход или выход и **открывает QR**. Каждое открытие = новая попытка и новый код на сервере. Закрыл экран и API ещё доступен — код отменён. Открыл снова — даже неиспользованный код заменён. Автообновления по таймеру нет. Обрыв wifi попытку не отменяет.

| Действие | Куда |
| --- | --- |
| Открыл QR (вход или выход) | `POST /attempts` |
| Закрыл экран, API ещё доступен | `POST /attempts/:id/cancel` |
| Кадр КПП после того, как телефон уже подтвердил QR | `POST /attempts/:id/decide` |

На `decide` уходит кадр КПП + уже подтверждённый QR; решение только на сервере. Подмена ответа в DevTools не должна открыть смену.

Демо из пакета: `_проходная_*` = кадр КПП (файл-загрузка, если нет камеры). `_фото` — не твой эталон, это админка.

Русские статусы. Живые данные API. Нарисованный «пропущен» без ответа сервера — снятие блока.

### `/phone` — рабочий, телефон

Обязательный сценарий: один раз получить право на QR; **сканировать** QR контролёра; слать гео раз в минуту в открытой смене; кнопки Бетон / Котлован / Курилка.

Админ при заведении связывает человека с учёткой. Ты не выбираешь `person_id` в теле.

| Действие | Куда |
| --- | --- |
| Телефон отсканировал QR и подписал nonce ключом устройства | `POST /attempts/:id/scan` |
| Гео каждые 60 с, только пока экран открыт и телефон разблокирован, или кнопка зоны | `POST /locations` |

`POST /locations`:

- только открытая смена; после выхода сервер координаты этой смены отвергает;
- кнопки **явно подписаны как симуляция**, тот же `POST /locations`, `source=button`;
- три зоны из пакета, имена кнопок: **Бетон** / **Котлован** / **Курилка**;
- гео с датчика — тот же путь, в данных это `gps|button`.

`POST /devices` — телефон сам регистрирует открытый ключ (`public_key`). Протокол не выдумывай: ключ на устройстве, в теле scan — `signature` nonce. Скопированный JWT без ключа сервер отвергает фразой «чужое устройство».

### Что не твоё, но нужно рядом

- `POST /people`, эталон, журнал UI — алисон
- `count_faces` / `embed` / `compare` — Шорохов, через API Влада
- `GET /site/now`, аналитика, помощник — алисон

Поля попытки, которые сервер хранит (не выдумывай другие): попытка, nonce, ttl, used, направление, итог, причина. Тело запросов — как напишет Владислав по этому черновику. Пока его нет — мок с этими смыслами, без новых полей вроде `allowed: true`.

## 4. Чеклист по порядку

### Первый час

1. Прочитай схему §«Экраны», §«Проход», §«API» и этот файл. Не пиши Владу «а как QR?».
2. Пустые `/gate` и `/phone`: русские заголовки «Контролёр» / «Рабочий», состояния пусто / загрузка / ошибка / успех. Без красоты.
3. На `/gate`: выбор **вход** / **выход**, кнопка открыть QR, кнопка закрыть (отмена), превью камеры или загрузка файла.
4. На `/phone`: экран сканера (камера или поле вставить код с мока), три кнопки зон с подписью «симуляция», индикатор гео 60 с.
5. Все вызовы — на мок (ниже). Контракт из схемы не менять.

### Клей

6. Как только живы `POST /attempts` и `POST /attempts/:id/decide` — снять мок. Склейка: открыл QR → телефон `scan` → планшет кадр → `decide` → на экране пропуск или причина.
7. Закрыл QR → `cancel`. Открыл снова → новый `POST /attempts`, старый код не работает.
8. Успешный вход → на телефоне пошла гео 60 с и кнопки. Успешный выход → гео этой смены больше не уходит (сервер всё равно отвергнет).
9. Повторить вход при открытой смене: вторая смена не создаётся — на экране русская причина с сервера.

### Сломать

10. **Чужое лицо:** эталон Гаджиева, на КПП кадр другого из пакета (`_проходная_*` Иванова и т.п.). Отказ, фраза в журнале, смена не открылась.
11. **Старый QR:** закрыл экран или открыл заново, телефоном сканируешь предыдущую картинку / фото экрана. Отказ.
12. **Повтор decide:** тот же успешный (или уже решённый) attempt ещё раз. Отказ. Фото старого QR — тоже отказ.
13. Чужое устройство / чужая учётка `worker` на чужой QR — отказ (личность из JWT).
14. Показать судьям экран с кнопками зон.

### Полировка

15. Крупный статус на планшете (пропуск / отказ) читается с метра. Телефон — одна колонка, без hover.
16. Нет камеры — русская ошибка и загрузка файла (судья принесёт фото).
17. Страница с камерой и геолокацией открывается по HTTPS, даже в локальной сети. Туннель, если он нужен, пишет алисон в `docs/run.md`.
18. Репетиция 10–15 мин: поменять текст кнопки / порядок шагов вслух.

## 5. Как работать, пока нет API и face

Мок на те же пути. Ответы отказа — **русский текст, не код**.

Пока Владислав ставит заглушку `decide` = «не готово» — рисуй эту фразу как есть.

Пример поведения мока (не контракт на поля, а смысл из схемы):

- `POST /attempts` → id попытки + материал QR. Повторный вызов — новый id.
- `POST /attempts/:id/cancel` → этот id больше нельзя scan/decide.
- `POST /attempts/:id/scan` → помечает попытку «QR подтверждён этим JWT».
- `POST /attempts/:id/decide` без предшествующего scan или с чужим кадром → отказ по-русски; после «успеха» повтор → отказ.
- `POST /locations` если «смены нет / смена закрыта» → отказ.

Камера: `getUserMedia`; запас — файл `_проходная_*` из `Первый пакет/Персонал/Гаджиев Магомед Ибрагимович/`.

Keycloak ещё лежит: кнопка «войти как gate / worker» только в dev, не вместо realm. Как алисон поднимет compose — переключить.

Compose правит только алисон. Нужен порт web — напиши ей в чат, сам `docker-compose.yml` не правь.

## 6. Приёмка

Отказы — русский текст, не код. Готовые фразы из схемы, их не переименовывать:

- заглушка Влада: **«не готово»**
- после выхода гео этой смены не принимается (текст даст API)
- старый QR, фото QR, повтор, чужое лицо, чужое устройство — отказ, фраза уходит в журнал

| Сделано | Не сделано |
| --- | --- |
| `/gate` и `/phone` открываются, свой сценарий целиком через UI | Решение «пропустить» на клиенте или галочка контролёра |
| Открыл QR = `POST /attempts`; закрыл = `cancel`; заново = новый код | Статичный QR, один и тот же код навсегда |
| Телефон сканирует QR планшета (`scan`), не показывает свой постоянный QR | Телефон «генерит QR для контролёра» |
| Кадр КПП + `decide` только после scan; на экране ответ сервера | `if (камера сняла лицо) пропущен` |
| Гео раз в 60 с только в открытой смене, пока `/phone` на экране и телефон разблокирован; кнопки Бетон / Котлован / Курилка, `source=button`, подписаны как симуляция | Свои интервалы, свои имена зон, отдельный API кнопок, обещание гео в фоне |
| Чужое лицо, старый QR, повтор decide — отказ на экране | Ломающие сценарии не проверены |
| Тексты по-русски, empty/loading/error | Английский UI, swagger как экран роли |
