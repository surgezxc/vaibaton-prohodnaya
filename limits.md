# Ограничения стенда

Этот документ фиксирует, что можно проверить на текущем локальном стенде и что ещё зависит от внешней интеграции.

## Состояние интеграции

- API находится в `apps/api` и описан в Compose. 10 октября 2026 года чистый запуск не состоялся: Docker CLI не смог подключиться к daemon (`unix:///Users/olga/.docker/run/docker.sock`), а исполняемый файл установленного `Docker.app` отсутствует. `docker compose config --quiet` прошёл, но сборка, API и соединение web с API не проверены.
- Compose подключает Face service из `deliverables/a-shorokhov-face-model/services/face`; его сборка и интеграция со сквозными сценариями не проверены. Проход и приём эталона не подтверждены запуском.
- Realm Keycloak и демонстрационные пользователи лежат в `infra/keycloak/prohodnaya-realm.json`. Для HTTPS адреса стенда в клиенте `web` нужно разрешить соответствующие redirect URI и web origin.
- Создание людей, проходы, журнал, аналитика и помощник зависят от API и БД. Пустые данные не заменяются вымышленными числами.

## План и геоданные

- В исходном пакете есть кадры камер зон, но нет готового плана площадки и точек GPS-привязки.
- Загруженное изображение плана хранится в `localStorage` браузера; геометрия зон и точки калибровки сохраняются через API. Изображение не синхронизируется между браузерами.
- Отдельного маршрута `/admin/zones` нет. Редактор открывается по `/admin` во вкладке «Зоны и схема».
- Без согласованного плана и трёх точек калибровки схема не задаёт физические координаты площадки.
- Порог «мало / много» не установлен. Тепловая карта показывает нулевые и ненулевые посещения и сравнивает ненулевые значения в выбранном периоде.
- Загрузка плана, сохранение трёх точек и полигона после обновления, а также фильтры, теплокарта, маршруты и помощник на `/manager` в браузере не проверены: web-сервис не запустился. Браузер вернул `ERR_CONNECTION_REFUSED` для `https://localhost:3000/admin/zones` и `https://localhost:3000/manager`.

## Браузер и запуск

- Геолокация телефона отправляется, только пока `/phone` открыт на переднем плане и экран устройства разблокирован. Фоновую отправку не обещаем.
- Камера и геолокация требуют HTTPS для доступа по локальной сети. Для телефона сертификат должен включать LAN-IP компьютера и быть доверенным на устройстве.
- В проверочной среде отсутствуют `mkcert`, Node.js и npm; локальный сертификат и запуск приложений вне Docker не проверялись.
- Текущее присутствие определяется открытой сменой из API, а не последней точкой геолокации.
- Стенд настроен для локальной демонстрации, не для промышленной эксплуатации.
- Локальная модель зависит от свободной памяти и скорости компьютера; подключение Ollama и производительность на машине команды не проверялись.
