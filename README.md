Скиллы и агенты Cursor, чтобы за 7–10 часов собрать контроль прохода на стройке. Кейс документов соискателей снят.

API (Hono): `apps/api`. Контракт — в [схеме](docs/architecture.md). Лицо считает `services/face` (ещё не в этом репозитории): пока его нет, `decide` пишет отказ «Распознавание лиц не готово».

```bash
cd apps/api
npm install
# Postgres и DATABASE_URL, см. apps/api/.env.example
npm test
npm run dev
```

В чате Cursor Agent: `/имя`. Каталог агентов — в таблице ниже и в `AGENTS.md`. В другой среде наличие этих файлов само по себе не гарантирует регистрацию команд и агентов.

Исходный кейс — предоставленный пользователем документ «Кейс 1. Проходная». Его копии в этом наборе нет; перед разработкой убедитесь, что документ доступен в контексте. Правила работы — в `AGENTS.md`; коммиты и отправка изменений требуют запроса пользователя.

## Старт

1. `/hackathon-vibe` — каденция и что не строить.
2. `/docs-defense` — git, `.env.example`, черновики `docs/`.
3. Параллельно агенты:

| Команда | Зачем |
| --- | --- |
| `/backend-pass` | сервер решает вход/выход, журнал, смены |
| `/gate` | планшет проходной |
| `/worker-phone` | некопируемое подтверждение + гео |
| `/enroll-admin` | эталон лица, отбраковка |
| `/analytics` | когда уже есть события: зоны в UI, кто внутри |
| `/assistant` | помощник + два провайдера модели |

4. Перед защитой: `/git-docs-defense` (чеклист) и `/hackathon-pitch`.

Судьи: заведут себя (Д9), попытаются пройти за другого (Д10). Клиентский «пропуск», статичный QR, «на кадре есть лицо» — дисквал.

## Модель

Слой один, переключение `MODEL_PROVIDER=gigachat|ollama`. Внешний — GigaChat, локальный — Ollama `qwen3:4b`. Как переключить — [docs/local-model.md](docs/local-model.md). Скилл `/model-layer`.
