# Агенты «Проходная»

Набор для вайбкодинга кейса контроля прохода на стройке. Продукта в репо нет. Документы соискателей сняты.

В чате Cursor: `/имя`. Скиллы — тоже `/имя`.

## Правила работы

- Соблюдай применимые инструкции родительского `AGENTS.md` и текущий запрос пользователя. Описания агентов и скиллов не расширяют разрешённый объём работы.
- Запрос на ознакомление или проверку не разрешает менять файлы. Отделяй найденные проблемы от предложений по их исправлению.
- Не создавай коммиты и не отправляй изменения без запроса пользователя. Примеры коммитов в скиллах — рекомендации для команды, а не разрешение выполнить Git-команды.
- Не меняй архитектуру, контракты и способы реализации в задаче, ограниченной правилами или документацией.
- Требования бери из предоставленного кейса. Рекомендации набора не выдавай за условия допуска; отсутствующие материалы и непроверенные предположения обозначай явно.
- Документируй фактическое состояние: не отмечай функцию или проверку готовой без подтверждения. В конце сообщай, что изменено, что проверено и что остаётся непроверенным.

## Кого звать

| Когда | Агент | Первый ход |
| --- | --- | --- |
| Планшет проходной | `/gate` | `/gate`: люди, вход/выход, камера |
| Телефон рабочего | `/worker-phone` | credential на устройстве, не статичный QR |
| Сервер прохода, журнал, смены | `/backend-pass` | `POST /attempts` + `decide` в транзакции |
| Завести человека, эталон, журнал UI | `/enroll-admin` | форма + отбраковка 0 / ≥2 лиц |
| Кто внутри, зоны, тепло | `/analytics` | список открытых смен + полигон в БД |
| Помощник и провайдеры модели | `/assistant` | `getModel()` + tool над БД |
| Доки, коммиты, Д9/Д10 | `/docs-defense` | `docs/*` + `.env.example` |

Старт: `/docs-defense` (bootstrap) → `/backend-pass` ∥ `/gate` ∥ `/worker-phone` ∥ `/enroll-admin`. Когда события пишутся — `/analytics` и `/assistant`.

## Инварианты

- Сервер решает проход. Нельзя пройти за другого.
- Лицо 1:1 с эталоном, не детектор.
- Два провайдера модели; GigaChat необязателен.
- Три браузерных UI. Русский копирайт. Без секретов в git.
