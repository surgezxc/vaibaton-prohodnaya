# Проходная: браузерный каркас

Next.js App Router + React + TypeScript. Node.js 22 или новее. Стили — обычный CSS, без отдельного UI-kit и внешних шрифтов.

## Запуск

Из корня репозитория:

```sh
cd apps/web
npm ci
npm run dev
```

Открыть `http://localhost:3000`, `/gate` — контролёр, `/phone` — рабочий. `/` позволяет выбрать экран. При занятом порте Next.js выводит другой адрес; можно явно задать порт: `npm run dev -- --port 3100`.

Для камеры на реальном телефоне нужен HTTPS. HTTP по IP компьютера в локальной сети может открывать страницу, но не даёт безопасный контекст для камеры. Настройка туннеля и стенда — следующий этап.

## Что реализовано

- Два адаптивных экрана с русскими состояниями и постоянной пометкой демонстрационного режима.
- `/gate`: выбор направления, открытие новой и закрытие локальной демо-попытки, ожидание и пример ошибки. Вместо сканируемого QR — явно подписанный макет.
- `/phone`: секции входа, камеры, смены, гео и кнопок симуляции. Кнопка демонстрирует загрузку и ошибку отсутствующего подключения; действия, требующие авторизации/смены, отключены.
- Общий предпросмотр камеры по явному действию пользователя. Остановка при выключении, скрытии страницы и уходе с маршрута. Поздний ответ запроса камеры после отмены освобождает полученный stream. Нет аудио, сохранения и отправки кадров.

## Что ещё предстоит

Keycloak, согласованный API-клиент, регистрация средства подтверждения, генерация и распознавание QR, отправка кадра и результата проверки, чтение состояния смены, геолокация раз в 60 секунд и запись событий зон. Сейчас сеть к backend не используется, проход не разрешается, данные о работнике/смене не выдумываются. Геолокация не запрашивается.

Для следующего этапа сверить [задачи Дениса](../../docs/tasks-demtory.md) и фактический backend. Протокол подтверждения и получение состояния попытки/смены требуют согласования; локальный демо-поток не является контрактом сервера.

## Проверки

```sh
npm run typecheck
npm run build
```

Общие компоненты в `src/components`, страницы в `src/app/gate` и `src/app/phone`. Обязательный root layout и общие стили уже созданы: для следующих ролей расширять этот каркас, не заводить второй проект.
