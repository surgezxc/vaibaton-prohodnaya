# Пакет Алисон

Снимок реализации задач Алисон: администратор, руководитель, зоны и план площадки, Compose и инструкции запуска. Файлы сохранены с исходной структурой проекта внутри этой папки, чтобы результат можно было просмотреть отдельно от текущей версии `apps/web`.

Это архив исходников на базе коммита `55a172d`. Для интеграции в общий запуск нужно переносить изменения из `apps/web/` и `docker-compose.yml` в корень репозитория с учётом более новых коммитов команды.
